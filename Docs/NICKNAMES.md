# Ники

> Случайные ники по умолчанию — `vibe-of-duty-p/assets/data/nicknames.txt`, по одному на строку. Тон — `Docs/AUTHOR.md` («Тон и юмор»).

## Правила

- Каждый ник — своя шутка. Без вариаций одной схемы (`Пельмень_Возмездия` / `Оладушек_Тьмы`), без постфиксов (`PRO`, `666`, `007`, `xX_…_Xx`, `Ультра`, `_на_Респе`).
- Абсурдный грубоватый юмор — да; злой над людьми — нет (внешность, тёщи, «тупой», тюремное «обиженный»).
- Грубых — ~1 из 20 по `AUTHOR.md` (сейчас 19 из 309).
- Регистр: заглавная — первое слово и имена собственные. Не длиннее 24 символов (поле имени).

## Что заходит

Мемы и абсурд (`Бамбарбия_киргуду`, `Превед_медвед`, `Ололо_пыщпыщ`, `Эщкере`), свинские каламбуры на знаменитостей (`Хрюк_Норрис`, `Хрюкс_Пистолс`, `Свинатра`, `Свинка_Пеппа_злая`, `Свин_Дизель`, `Свинго_Старр`), игрок-школьник (`Я_у_мамы_снайпер`, `Ещё_одну_катку_мам`, `Мам_купи_донат`, `Батин_аккаунт`), армия в быту (`Гранатомёт_в_ипотеку`), грубое с поворотом (`Один_хрюк_один_пук`, `Дядя_Пердимонокль`, `Бабка_Жопкина`, `Граф_Пердула`, `Синьор_Пердуччи`, `Сракозябра`, `Жопенгаген`, `Химоружие_из_гороха`, `Хрюкнул_обоими_концами`).
