# Боты-архетипы (тесты баланса)

> Зачем: гонять оружие против оружия без людей, но со стилями живых игроков и с разным навыком. Цифры — сбор информации для владельца, не правила баланса. Стили — игроки плейтеста 2026-11-02 (`Docs/balance/playtest_2026-11-02.md`, «Технические архетипы»); уровни навыка и все числа ботов — Claude, не владелец.

## Запуск

```
bash vibe-of-duty-p/tools/bots.sh СЕКУНДЫ СТИЛЬ:НАВЫК:КОМПЛЕКТАЦИЯ [...]
bash vibe-of-duty-p/tools/bots.sh 120 tapok:average:pdw larry:average:ak
python vibe-of-duty-p/tools/stats_report.py stats/bots --bots
```

- Выделенный сервер на тестовой карте `field` пишет статистику (`--stats`), по клиенту headless на бота. Матч один, без лимита убийств. Статистика копируется в `stats/bots/` (корень репозитория). Имя бота — `стиль-навык`.
- Комплектация — id без `kit.`: `ak`, `acr`, `aug`, `m16`, `groza`, `val`, `mp7`, `p90`, `pdw`, `winchester`, `striker`, `contender`, `mk14`, `khruger`.
- Переменные: `MAP=` — другая карта, `HARDCORE=1` — галочка «Хардкор», `VOD_PORT=N` — свой порт и своя копия проекта (`%TEMP%\vod-bots-N`), чтобы гонять несколько прогонов рядом. Больше 2–3 прогонов по 5 ботов параллельно — сеть начинает терять пакеты (`gaps` в строке сервера).
- Отчёт с `--bots`: строки «стиль-навык · оружие», потом сводки по стилю, навыку и оружию; «Кто кого» — по ботам.
- Аргументы клиента: `--bot-style=ID --bot-skill=ID --build=kit.ID`.

## Матрица

```
bash vibe-of-duty-p/tools/bots_matrix.sh [СЕКУНДЫ=180] [НАВЫК=average] [ПАРАЛЛЕЛЬНО=2]
python vibe-of-duty-p/tools/stats_report.py stats/bots/matrix_<навык>_<дата> --bots
```

- 14 матчей по 5 ботов, по одному на стиль. В матче i стиль j берёт комплектацию (i + 3j) mod 14: за 14 матчей каждая комплектация ровно раз играет каждым стилем и встречает разных соперников. `HARDCORE=1` — хардкор (папка с `_hardcore`).
- 180 с по 2 параллельно — около 30 минут. Статистика — в `stats/bots/matrix_…`.
- В отчёте с `--bots` — таблица «Оружие × стиль» (К/Д, убийства / смерти).

## Карта `field`

Ровный квадрат 50 × 50 м со стенами, 8 точек спавна по кругу в 22 м от центра лицом к центру (`prefabs/levels/field.tscn`, тестовая — в меню нет). Укрытий нет: боты не умеют обходить препятствия (навигации нет — идут прямо на ближнего врага). Значит, тест меряет оружие и стиль в открытом бою на дистанции, которую выбирает стиль; засады, углы и укрытия не меряет. Другие карты (`MAP=`) запускаются, но боты там упираются в стены.

## Что делает бот (`PlayerBots._bot_arch_cmd`)

- Цель — ближний враг в прямой видимости (луч от глаз до груди); никого не видно — идёт к ближнему.
- Видит то, что показывает его клиент (чужие игроки интерполированы, как у человека).
- Замечает цель через `react` с после появления в видимости, до этого прицел стоит.
- Целится туда, где цель была `react` с назад, с упреждением по её тогдашней скорости в доле `lead`; поворачивает не быстрее `turn` °/с.
- Рука гуляет: медленное случайное блуждание вокруг точки (Орнштейн — Уленбек, 0.35 с) со стандартным отклонением `noise` °. Бот его не чувствует — отсюда промахи.
- Гасит долю `recoil` отдачи.
- Раз в секунду выбирает, целиться в голову (доля `head`) или в грудь.
- Стреляет, когда прицел в пределах `gate` ширин тела (0.7 м) от точки, куда он целится; от `ads_from` м — в прицел и только после полного подъёма; очередями `burst` с паузой `pause` или держит спуск. Полуавтомат — отпускает спуск между выстрелами. Акимбо — оба спуска от бедра.
- Вне боя перезаряжает магазин, если в нём меньше половины.

## Калибровка (2026-11-07)

Все с АК (`ak`), 5 стилей в одном матче, 90 с, точность — попадания / выстрелы на сервере. «Люди» — плейтест 2026-11-02 (там разное оружие).

| | Тапок | Степашка | Ларри | Владелец | Рулька |
|---|---|---|---|---|---|
| новичок | 14 % | 20 % | 4 % | 11 % | 8 % |
| средний | 18 % | 31 % | 14 % | 22 % | 17 % |
| опытный | 34 % | 50 % | 23 % | 30 % | 26 % |
| профи | 58 % | 80 % | 35 % | 39 % | 41 % |
| люди | 25 % | 15 % | 15 % | — | 24 % |

- «Средний» близок к людям плейтеста по Ларри и Рульке; живой Тапок — между «средним» и «опытным», живой Степашка — ниже «новичка» по точности: бот-Степашка подходит на 3 м, где попадает всё, живой стрелял на бегу издалека.
- Выборки по 90 с — по 5–15 смертей на бота; выводы по К/Д — только с длинных прогонов.

## Ограничения

- Нет укрытий, обхода, засад и гранат (боты берут только комплектацию из `--build`).
- Бот знает, где враг, и за стеной (идёт к ближнему) — на `field` стен нет, неважно.
- Числа навыка подобраны по точности на АК, не по ощущению.
