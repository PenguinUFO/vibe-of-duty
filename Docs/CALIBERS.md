# Калибры стволов

> Сводка по калибрам и патронам: что стоит в игре сейчас и что было и убрано. Выбор калибра в редакторе владелец убрал 2026-10-23: у каждого ствола один базовый калибр. Дозвуковой патрон живёт только в карточке «Глушитель» (`Docs/LOADOUT.md`, «Карточки»). Ниже лежат числа убранных вариантов, в формате `weapons.cfg`, чтобы их можно было вернуть.

## Сейчас в игре

| Ствол | Базовый калибр | Карточка «Глушитель» |
|---|---|---|
| АК | 7.62×39 (ПС) | ПБС на том же патроне: −10 дБ, щелчок пули остаётся |
| ACR | 5.56×45 NATO (.223 Remington) | глушитель + .300 AAC Blackout (7.62×35) дозвуковой: −16 дБ |
| MP7 | 4.6×30 (DM11, бронебойный) | глушитель + 4.6×30 дозвуковой: −16 дБ |
| PH IDW | .45 ACP | нет: глушитель уже штатный (.45 дозвуковой сам по себе, −16 дБ) |
| Люгер | 9×19 | нет: глушителя к P08 нет |

## Убранные варианты

Числа — оценки, а не замеры, и не сыграны. Модуль калибра применялся первым, до остальных модулей.

### АК: 5.45×39 (как у АК-74)

Убран 2026-10-23 вместе со своими магазинами.

```ini
[ak.caliber.545]
name = "5.45×39"
info = "Как у АК-74: урон ×0.85, отдача ×0.7, дальше бьёт, патронов в запасе больше."
damage_mult = 0.85
recoil_up_mult = 0.7
recoil_side_mult = 0.8
falloff_ranges_mult = 1.2
reserve_start_mult = 1.25
reserve_max_mult = 1.25

[ak.mag.rpk45]      ; только с 5.45
name = "Магазин РПК-74 45"
mag_size = 45
reload_time_mult = 1.15
ads_time_mult = 1.1

[ak.mag.casket60]   ; только с 5.45
name = "Магазин-«гроб» 60"
mag_size = 60
reload_time_mult = 1.4
ads_time_mult = 1.2
```

**Старый ПБС у АК** («глушитель на дозвуковых»): −14 дБ, урон ×0.9, урон падает раньше (×0.8), прицеливание ×1.1. Владелец заменил его карточкой «глушитель на базовом калибре».

### ACR: 6.8 SPC

Комплект смены калибра. Убран 2026-10-23.

```ini
[acr.caliber.68]
damage_mult = 1.25      ; 6 попаданий вместо 7
recoil_up_mult = 1.4
recoil_side_mult = 1.3
mag_size = 25
reserve_start_mult = 0.85
reserve_max_mult = 0.85
```

### ACR: .300 AAC Blackout дозвуковой

Теперь он только в карточке, вместе с глушителем. Оценка от 5.56:
- **пуля:** 220 гран на ~310 м/с, импульс ×1.2;
- **урон:** ×1.13, это 26 и 6 попаданий;
- **потеря урона:** начинается рано (×0.55): с 16.5 м;
- **пробивание укрытий:** ×0.6;
- **магазины:** те же, на 30;
- **громкость:** пуля не щёлкает, без глушителя тише на 6 дБ.

Отдельным калибром, без глушителя, он был таким:

```ini
[acr.caliber.300]
damage_mult = 1.13
falloff_ranges_mult = 0.55
penetration_mult = 0.6
recoil_up_mult = 1.2
recoil_side_mult = 1.2
loudness_add = -6.0
```

### MP7: 4.6×30 дозвуковой

Теперь он только в карточке. Оценка:
- **пуля:** тяжелее, ~300 м/с против ~720 у DM11, энергии вдвое меньше, без сердечника;
- **урон:** ×0.8, это 14 и 11 попаданий;
- **потеря урона:** с 15 м;
- **пробивание укрытий:** ×0.33;
- **бронебойность:** нет;
- **отдача:** ×0.8;
- **громкость:** без глушителя тише на 4 дБ.

```ini
[mp7.ammo.subsonic]
loudness_add = -4.0
damage_mult = 0.8
falloff_ranges_mult = 0.5
penetration_mult = 0.33
armor_piercing = false
recoil_up_mult = 0.8
recoil_side_mult = 0.8
```

### PH IDW: 9×19

Калибр первых прототипов. Убран 2026-10-23. Ниже абсолютные числа с глушителем, который на IDW штатный.

```ini
[pdw.caliber.9]
damage = 25.0
mag_size = 32
reserve_start = 128
reserve_max = 192
recoil_up = 0.18
recoil_side = 0.036
falloff_ranges = [15.0, 30.0]
```

### PH IDW: 10mm Auto

Убран 2026-10-23. По заявлению разработчиков 90-х, конструкция и регулируемый затвор держат этот патрон. Оценка от 9×19:
- **пуля:** 180 гран на ~400 м/с, энергия ×1.6;
- **урон:** 33, это 5 попаданий;
- **потеря урона:** позже, с 19 м;
- **пробивание укрытий:** 0.15 м;
- **отдача:** сильнее;
- **громкость:** патрон сверхзвуковой, с глушителем −10 дБ.

```ini
[pdw.caliber.10]
damage = 32.5
mag_size = 30
reserve_start = 120
reserve_max = 180
recoil_up = 0.29
recoil_side = 0.054
falloff_ranges = [18.75, 37.5]
penetration = 0.15
loudness = -10.0
```

**PH IDW без глушителя** (модуль убран: глушитель у IDW всегда стоит): −3 дБ, вспышка и трасса, отдача ×1.11, прицеливание ×0.91, скорость ×0.95.
